# このデバイスで常に守ること

このファイルは、各デバイスのエージェントの個人設定から読み込まれ、どのプロジェクトの会話でも毎回読まれる。短く保つ。

- 解説文書やチャットの回答について、ユーザーが記録を指示したら（「記録して」「残しておいて」など）、`~/dev-management-private/writing-loop/README.md` を読み、その手順で `records/` に下書きを作る。記録は作業中のプロジェクトではなく `~/dev-management-private` にコミットする
- 記録と、Skill の改訂（ルール化）は、エージェントから提案しない。ユーザーが始めたときだけ行う
