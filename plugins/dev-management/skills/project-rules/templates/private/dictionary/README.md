# dictionary — 概念の辞書

読み手が知らなかった概念を、読み手が理解した言葉で説明した辞書。1語1ファイル。

一般に使われている言葉（見出し）を忘れたり分からなくなったりしたときに引けば、以前の読み手がどう解釈していたかが分かる。エージェントは説明を書く前にこれを引き、同じ言い回しや図を使う。別の文書で同じ概念が出てきても同じ説明に揃うので、読み手は概念を覚えていける。

## 項目の形

`_template.md` をコピーして使う。ファイル名は見出しの語（英語の語は小文字とハイフン。例：`reward-hacking.md`）。

| 欄 | 中身 |
|---|---|
| 見出し | 用語や概念の言葉（一般に使われている表現） |
| 解説の要否 | `不要` か、空欄 |
| 説明 | 読み手が理解できる言葉での説明。読み手が言い直して合っていた言葉があれば、それを使う |
| 図 | 必要なら Mermaid で |

### 解説の要否の印

`不要` は、読み手が既にイメージできる語に付ける。**印があっても、辞書の項目には説明を書く。** 印が効くのは、その語を使う文書や回答の側である。

- 文書・回答では、`不要` の語に括弧の説明（「VLA（vision-language-action モデル：画像情報を元に行動を出力するモデル）」のような）を付けない。なぜそれが起きるか、などの説明は必要に応じて書く
- 自律レビューの読み手は、`不要` の語に説明が無くても止まらない。長く説明していたら止まりとして挙げる
- 診断は、`不要` の語に説明を足す指示を出さない

## 登録の手順

1. 読み手が知らない概念の解説を求め、エージェントが答える
2. エージェントが、辞書に登録するかを尋ねる
3. 合意したら、同じ語や同じ概念の項目が既にないか探す。あれば読み手に示し、統合するか確認する
4. 項目を作り、このリポジトリにコミットする（push はユーザーが指示したときだけ）

## 文書からの参照

文書の中では、辞書の項目へのリンクで済ませてよい。主に使うのはエージェント（VSCode 上の Claude Code）。読み手が文書の中にも説明を書くよう指示したときは、その文書に書く。
