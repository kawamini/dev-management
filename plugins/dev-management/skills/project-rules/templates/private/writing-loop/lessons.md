# 教訓

事例集（`records/`）から取り出した、場面を越えて使える書き方の教訓。文書を書く・回答するときに、書く前に通して読む。手順は `README.md` の §1・§3。

各教訓は次の形で書く。

```markdown
### L<番号> <何をしないか／何をするか>
- 場面：<どんな文を書いているときに外しやすいか>
- 書くこと：<その場面で何を書くか>
- 代表例：<事例の番号と、直す前と直した後のどの部分か>
- 事例：<根拠になった事例の番号>
- 原則：<research-explainer-style の原則の番号。当たるものが無ければ「該当なし」>
```
